# Dra. Emille Andrade — prévia conceitual

Adaptação independente do modelo `taisgb/alexandre-magno-modelo`: mesmas seções, classes principais, composição da hero, menu em cápsula, cards, animação e navegação. CSS consolidado e personalizado. Nenhum arquivo do modelo original foi modificado.

## Executar
Abra `index.html` diretamente ou execute `npm install` e `npm run dev`. Para GitHub Pages, publique a raiz da branch main (não precisa de build). Para Vite, `npm run build`.

## Antes de enviar/publicar definitivamente
- Trocar os recortes provisórios da captura fornecida por fotos originais autorizadas e a logo original de alta resolução. Os recortes não foram retocados.
- Confirmar CRM/RQE, nome civil, formação e serviços. Não foram incluídos registros divergentes ou especializações não confirmadas.
- Confirmar telefone, endereço e horários com a médica.
- O Instagram é um link, não um feed ao vivo. Não reproduzimos depoimentos de pacientes.
- O site é uma prévia não oficial com noindex/nofollow. Fontes, ícones e mapa dependem de conexão externa.
